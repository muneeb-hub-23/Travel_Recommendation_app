📋 Overview

Travel Recommendation App is a Django REST API with ML-powered travel recommendations using spaCy NLP and scikit-learn content-based filtering.

Tech Stack: Django 4.2, DRF, MySQL, spaCy, scikit-learn, NumPy

🏗️ System Architecture

🔑 Key Relationships:
  • UserPreference.user_id → User.id (One-to-One, CASCADE)
  • Review.user_id → User.id (Many-to-One, CASCADE)
  • Review.destination_id → Destination.id (Many-to-One, CASCADE)
  • Review: UNIQUE(destination_id, user_id) - One review per user per destination
